# 🎮 Jogo da Velha em Java

Jogo da Velha (Tic-Tac-Toe) para 2 jogadores, desenvolvido em Java com foco em **Programação Orientada a Objetos**.

## 🚀 Como rodar

1. Clone o repositório
2. Abra o projeto no IntelliJ IDEA
3. Rode a classe `Main.java`

## 🧠 Conceitos aplicados

- **Abstração**: Classes `Jogador`, `Tabuleiro`, `Jogo`
- **Encapsulamento**: Atributos privados com getters
- **Composição**: `Jogo` tem `Tabuleiro` e `Jogador`
- **Enum**: `Simbolo` (X, O, VAZIO)
- **Exceções**: `IllegalArgumentException` para jogadas inválidas

## 🎯 Como jogar

- O jogo pede linha e coluna (0 a 2)
- Jogador 1 é **X**, Jogador 2 é **O**
- Vence quem fizer 3 em linha (horizontal, vertical ou diagonal)
